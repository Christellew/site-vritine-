# Site vitrine

Projet de site vitrine réalisé en HTML et CSS dans le cadre de ma formation Product Builder No Code & IA.



## Aperçu du projet

Ce projet consiste à créer un site vitrine professionnel, conforme à une maquette client, responsive, propre et accessible en ligne.

Le site a été développé avec HTML5 et CSS3, versionné avec Git et GitHub, puis publié sur un hébergement web Hostinger.



## Technologies utilisées

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code
- Hostinger pour l'hébergement


## Installation

Pour récupérer et ouvrir le projet sur un ordinateur :

1. Cloner le dépôt GitHub :

```bash
git clone https://github.com/christellew/site-vritrine-.git
```
2. Ouvrir le dossier du projet dans Visual Studio Code.

3. Ouvrir le fichier `index.html`.

Lancer `index.html` dans un navigateur.

Aucune installation de dépendance supplémentaire n'est nécessaire.

## Police utilisée

Police principale : **Heebo**  
Source : **Google Fonts**

La police est chargée dans le fichier `index.html` avec les lignes suivantes :

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Heebo:wght@100..900&display=swap" rel="stylesheet">
```
La police est ensuite utilisée dans le fichier `style.css` avec :

```css
body {
    font-family: "Heebo", sans-serif;
}
```
